# 🚲 YouBike E-Bike 資料擷取系統

## 專案簡介

本專案為元智大學自主學習小組專案，主題為 YouBike 電輔車（E YouBike）資訊查詢系統。

專案目標為擷取 YouBike 官方資料，查詢桃園市中壢區符合指定條件之 E YouBike 車輛資訊，並將結果提供給前端頁面進行展示。

---

## 我的負責內容

本人主要負責後端資料擷取與資料處理部分，包括：

- Python 爬蟲程式撰寫
- YouBike 資料來源分析
- 場站資料擷取
- E YouBike 資訊篩選
- 資料清理與排序
- 輸出前端所需資料格式

---

## 功能實作

### 資料擷取

透過 Python 連接 YouBike 公開資料來源，取得場站與車輛相關資訊。

### 資料篩選

依據指定關鍵字篩選符合條件之站點，例如：

- 元智大學
- 大學
- 中壢

### 資料排序

依作業需求進行排序：

1. 場站編號遞增排序
2. 相同場站依電量遞減排序

### 資料輸出

將整理後資料提供前端頁面顯示。
